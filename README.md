# mutualfunds-mufap

Scheduled scrapers for Pakistani market data. GitHub Actions fetch pages from
[MUFAP](https://www.mufap.com.pk) (mutual fund NAVs) and
[PSX](https://dps.psx.com.pk) (stock screener and ETF quotes), clean them into
simple HTML tables, and commit the results to `files/` on `main`.

## Output

| File | Source |
| --- | --- |
| `files/mufap.html` | MUFAP daily industry statistics (raw page) |
| `files/psx.html` | PSX screener (raw page) |
| `files/psx-table.html` | Cleaned screener table |
| `files/etfs/<TICKER>.html` | Raw PSX ETF quote page (`MZNPETF`, `JSMFETF`) |
| `files/etfs/<TICKER>-table.html` | One-row summary table for the ETF |

Files under `files/` are generated by the workflows. Don't edit them by hand.

## Workflows

| Workflow | Schedule (UTC) | What it does |
| --- | --- | --- |
| `psx.yml` | 04:30, 06:30, 08:30, 10:30, Mon-Fri | Fetch PSX pages, parse, commit |
| `mufap.yml` | 14:30, Mon-Fri | Fetch the MUFAP page, commit |
| `retry.yml` | On failure of either workflow | Re-run failed jobs (up to 3 attempts) on a fresh runner |

All workflows can also be started manually with `workflow_dispatch`.

## Running locally

Requires Python 3.12.

```sh
pip install ai-cloudscraper beautifulsoup4

# Fetch a page (HTML on stdout, retry logs on stderr)
python cloudflare-scraper.py "https://dps.psx.com.pk/screener" > files/psx.html

# Clean the screener table (reads files/psx.html, writes files/psx-table.html)
python parse-psx.py [--limit N] [--html-output PATH]

# Summarise an ETF quote page
python parse-psx-ticker.py files/etfs/MZNPETF.html files/etfs/MZNPETF-table.html
```

Run these from the repository root, since the parsers use relative paths.

## How fetching works

`cloudflare-scraper.py` uses `cloudscraper` to get past Cloudflare. Transient
failures (dropped connections, 403/404/429/5xx) are retried up to 5 times with
exponential backoff. If every attempt fails, the script exits non-zero and the
workflow stops before committing anything.
